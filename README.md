# キャンプ持ち物チェック

キャンプの持ち物をカテゴリ別にチェックできる、自分専用のチェックリストアプリです。
サーバーやビルドは不要な素のHTML/CSS/JSで作られていて、データはスマホのブラウザ内（localStorage）にのみ保存されます。

## 特徴

- カテゴリ別に持ち物をチェック（例：基本装備、調理、アヒージョ、焚き火...）
- 同じアイテムが複数カテゴリにあっても、実体は1つの「アイテムマスタ」なので、どこかでチェックすると全カテゴリで連動してチェックが付く
- キャンプ回ごとにチェック状態を記録（過去の記録も一覧から見返せる）
- カテゴリ・アイテムは「マスタ管理」タブから自由に追加・編集・削除
- データの書き出し（JSON）・読み込み・全初期化に対応
- スマホのホーム画面に追加してアプリのように起動できる（PWA対応）

## デプロイ方法（GitHub Pages・無料）

1. GitHubの本リポジトリの **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` にする
3. **Branch** をこのアプリを配置したブランチ（例: `main`）、フォルダは `/(root)` を選んで **Save**
4. 数分後、`https://<ユーザー名>.github.io/camp-belongings/` で公開されます

## ローカルでの確認方法

```
python3 -m http.server 8000
```

を実行し、ブラウザで `http://localhost:8000/` を開いて確認できます。

## データについて

すべてのデータはブラウザのlocalStorageに保存されます。別の端末やブラウザとは共有されません。
機種変更などに備えて、「マスタ管理」タブの「書き出し」でJSONファイルをバックアップしておくことをおすすめします。
